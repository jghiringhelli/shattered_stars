# Maneuver Dial Definitions

> Per-ship maneuver dial specifications: speed, bearing, and difficulty for every ship in the game.

---

## Reading the Dials

Each cell shows the **difficulty** of that maneuver at that speed:

| Symbol | Difficulty | Effect |
|--------|-----------|--------|
| **G** | Green | Removes 1 stress token |
| **W** | White | No stress effect |
| **R** | Red | Adds 1 stress token |
| **-** | Not available | Ship cannot perform this maneuver at this speed |

**Bearings**: TL = Turn Left, BL = Bank Left, ST = Straight, BR = Bank Right, TR = Turn Right, KT = K-Turn, SL = Segnor's Loop, TaR = Tallon Roll.

## Special Maneuver Reference

| Maneuver | Ships That Have It | Default Key | Stress? |
|----------|-------------------|-------------|---------|
| K-Turn | Most ships (speed 3-5) | Z | Red (except TIE Defender: White) |
| Segnor's Loop | A-Wing, B-Wing, TIE Defender, TIE Advanced, TIE Phantom | Z + A/D | Red |
| Tallon Roll | A-Wing, B-Wing, TIE Defender, TIE Advanced, TIE Phantom | Z + Ctrl + A/D | Red |
| SLAM | K-Wing only | K | No stress, but no actions after |
| Cloak | TIE Phantom only | C | No stress, lasts 1 turn |
| Stop (speed 0) | U-Wing only | S (hold) | Red |
| Barrel Roll | Multiple ships | Shift + A/D | No stress |
| Boost | A-Wing, TIE Interceptor | Shift + W | No stress |
