# Movement lab: template vs analog steering

Generated by `npm run movement:lab` (ship `terran_viper`, throttles 3, 2). Deterministic: fixed 60 Hz ticks, seeded duels. Analog rows fly the default analog tuning (bank 70 / hold off; the tabletop preset is 45° / 90°, see docs/specs/flight-controls.md).
Pilots: *proportional* presses what the heading error asks for (template: Q/E for ≥ 18°, the arrow for ≥ 5°: the best template thresholds of a sweep; analog: the one key while there is error);
*tapper* only taps the arrow (100 ms down, a pulse every 233 ms: never reads as a roll) while there is error; *fast-tapper* pulses every 150 ms (75 ms down), inside the 220 ms barrel-roll double-tap window.

## Battle emulation (real skill arena, seeded)

Ships `terran_gladius`, `confed_sparrow` (same hull on both sides; results are pooled over the ships), at least 30 seeded rounds per cell and ship (seed = round + 1; the subject flies side A in even rounds and B in odd ones), 120 s game-time limit (timeouts are decided on points). Squads (2v2, 4v4 bots) coordinate with orders and a squad mark; the human-like pilot ignores orders and flies on its own.
*Human-like pilot*: sees enemies 150-250 ms late (drawn per pilot), chases the nearest, presses the proportional-policy keys (template: Q/E ≥ 18°, arrow ≥ 5°, instant cut; analog: the one key while there is error), slows to its hard-turn speed to line up a shot and opens up on a far target; no specials, boost or rolls.
Meters are the subject's: wedge % = time with an enemy inside the ship's own firing arc and range; stress = mean stress level (0-1); turns = key-down starts (analog) or turning cycles started (template); at speed cap = ticks flown below the set throttle; heading accel RMS = roughness of the heading rate.
